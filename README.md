Clean water starts with trustworthy data. When agencies 
have confidence in what their sensors are telling them, 
they can respond faster, enforce smarter, and protect 
public health before problems escalate.

So I built a solution.

📊 What I created:
An end-to-end Data Quality Framework in Microsoft Power BI using 28 years of real river monitoring data from Northern Ireland.

🔍 The Data Reality:
- 141,431 readings across 890 monitoring sites
- Zinc, Iron & Copper data — 86%+ missing
- Trust Score: 70/100 — amber zone

📈 Key Findings:
- BOD (organic pollution) declined over 28 years ✅
- Nitrate levels improved — less agricultural runoff ✅
- pH & Dissolved Oxygen stable & healthy ✅

🛠️ Tools Used:
Power BI · Power Query · DAX · DAMA DQ6 Framework
